# Merchandiser AI Enterprise v8

## Explainable Retail Decision Experience

v7 deepens the existing v6 application without changing the underlying data model or approval workflow.

### New capabilities

- Executive Health framework: business, financial, inventory, supply-chain and OTB scores
- AI Executive Briefing based on current sales, stock, OTB and capital-optimizer results
- Revenue-at-risk, inventory-at-risk and potential-recovery measures
- Decision Explainability screen with demand, inventory, lead time, safety stock, service-level and financial drivers
- Digital Twin scenario comparison: No Buy, Recommended, Increase 20%, Reduce 15%
- Executive Decision Timeline for recommendations, edits, approvals, rejections and PO creation
- Existing v6 modules preserved

### Run on Windows

Double-click `run_all.bat`, keep both command windows open, and browse to:

- Application: http://127.0.0.1:5500
- API docs: http://127.0.0.1:8000/docs

### Important

This remains a local pilot/demo application. The Digital Twin and explainability outputs are deterministic planning simulations, not guaranteed commercial outcomes. Validate configuration and recommendations against real retail data before production use.
