# Merchandiser AI Enterprise v9

Interactive decision-experience upgrade built on the stable v8 backend.

## Added
- Executive cockpit with clickable risk and planning indicators
- SVG sales, category, store and forecast visualizations (no external chart dependency)
- Product 360 tabbed workspace with store heatmap and decision drivers
- Digital Twin sliders, scenario assumptions and side-by-side comparison
- Workflow Kanban with quick approval actions
- Evidence-grounded Planning Assistant with cited application modules
- Responsive layouts and deeper KPI drill-downs

## Run
Double-click `run_all.bat`, keep both windows open, then visit http://127.0.0.1:5500.
