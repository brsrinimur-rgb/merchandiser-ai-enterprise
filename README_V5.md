# Merchandiser AI 360 v5

Enterprise Retail Planning, Buying Intelligence & Decision Control Platform.

## v5 additions
- Retail Command Center with composite health score
- Executive risk/opportunity cockpit
- AI Planning Assistant using live API evidence (rule-driven, no external AI key required)
- Visual Workflow Kanban board
- Dark/light appearance toggle
- Responsive tablet/mobile improvements
- Stronger executive branding and KPI presentation

## Existing capabilities preserved
Advanced replenishment, stock intelligence, transfers, category management, OTB, capital optimizer, supplier performance, forecasting, imports, category settings, approval workflow, audit history and automatic PO creation.
